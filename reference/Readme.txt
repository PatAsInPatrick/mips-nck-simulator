cpu_simulator_python-main32
	ปรับเพิ่ม Register เป็น 32 ตัว
	แสดงค่า PC แบบหลอกตาเป็นฐาน 16 คำสั่งละ 4 byte (บรรทัดที่ i แสดงค่า hex(i*4))
	แสดงผล register ทั้ง 32 ตัวให้ดูง่ายกว่าแบบเดิม
		จะแสดงทุกคำสั่งก็ได้ ตอนนี้ให้แสดงครั้งเดียวหลังทำทุกคำสั่ง

cpu_simulator_python-main32V2
	เพิ่มส่วนแสดงผล Memory ด้วย memory.dump() พิมพ์ดิกชันนารีออกมาให้ดู ทุกครั้งที่พิมพ์ค่า register ออกมาดู
		ในอนาคตถ้าแสดงทั้งหมด (รวมทั้งส่วนของคำสั่งเป็นแบบตารางทุกตำแหน่ง ก็จะเป็นการแปลงคำสั่งเป็น hex ให้ดูได้ด้วย เรียกว่า assemble)
	เพิ่ม isa.decode2() ทำการแปลง register rd rs rt offset immediate ให้เป็น int ไว้รอ
		จำแนกคำสั่งที่มี operand รูปแบบเดียวกันไปเรียกส่วนเตรียมพร้อมเดียวกัน
		เพราะว่าหลายๆ คำสั่งต้องการทำแบบนี้ จะได้ไม่ต้องเขียนซ้ำๆ ใน cpu.execute() ทำให้เขียนส่วนการทำงานของแต่ละคำสั่งสั้นลง และเพิ่มคำสั่งได้ง่ายขึ้น (มั้ง มีบางกรณีที่ต้องทำความเข้าใจ)
		เช่น lw rt offset(rs) เวลาเตรียม จะเตรียมไว้เป็น  lw rt rs offset แทน
	เพิ่มบางคำสั่ง รองรับเท่าที่มีในไฟล์ instructions.txt

หมายเหตุ 
	ยังสมมติให้ PC เริ่มจาก 0 ทำให้การ jump ทำได้สะดวก แต่ยังไม่ทำ เพราะยังรอให้ PC ย้ายตำแหน่งเริ่มได้ก่อน เพื่อชดเชย index ของ list ที่ PC ไม่เริ่มจาก 0 เวลา jump
	ทำถึงตอนนี้ก็ยังสั้นพอที่จะทำความเข้าใจได้ง่ายอยู่ ถ้าเพิ่มอะไรเข้าไปอีกเยอะๆ ผมว่าจะอ่านยากแล้ว ต้องเริ่มศึกษาทำความเข้าใจจากที่เขียนไว้สั้นๆ ก่อน
		เช่นถ้าเพิ่มส่วน assembler เข้าไปจะสับสนเกี่ยวกับการทำงานของโปรแกรมได้ เหมือนวนทำเรื่องเดิมซ้ำ ไว้จะอธิบายเพิ่มทีหลัง
